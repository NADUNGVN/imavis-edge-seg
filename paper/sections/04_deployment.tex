\section{Deployment Protocol}
\label{sec:deployment}

Each static level is exported and compiled independently for TensorRT GPU, a Xavier DLA-targeted path, and a Hailo HEF. The DLA path is scoped as a secondary encoder-only ablation: the confirmed limit of 16 subgraphs per DLA core is already exhausted by the encoder, so the full decoder falls back to GPU. TensorRT GPU and Hailo HEF are therefore the primary backends for headline hardware claims.

The benchmark protocol uses batch size one, at least 200 warm-up inferences, at least 5,000 timed frames, three independent runs, and complete toolchain disclosure. Kernel-only and host-plus-DMA latency are reported separately. The benchmark harness records p95 latency and bootstrap confidence intervals where the backend exposes sufficient per-inference data. No energy-per-frame number is claimed until an external calibrated power meter is available; the current Hailo-8 M.2 module has no usable on-board power/current sensor.
