# Submission packages

Submission sources are versioned by venue and date. Each directory must be self-contained and must not depend on files from an earlier draft.

## Current package

- [`ivc_2026-09-29/`](ivc_2026-09-29/): Image and Vision Computing manuscript using `elsarticle`, with six editable TikZ/PGFPlots figures, highlights, upload instructions, and an evidence manifest.

When a review round changes manuscript claims or structure, create a new dated submission directory and link it from the corresponding review-round README.
